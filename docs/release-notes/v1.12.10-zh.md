## Overview

v1.12.10 修复公开仓库的容器发布链路：GHCR 镜像现在按当前仓库所属命名空间发布，避免公开仓库的 Actions 使用无权访问其他组织镜像包的问题。

## Highlights

### Fixes

- Release workflow 根据当前仓库 owner 生成 GHCR 镜像地址，公开仓库可以使用自身的 Actions `packages: write` 权限完成镜像发布。
- 原生安装包、GitHub Release 和 Telegram 通知继续沿用现有发布流程。

## Upgrade Notes

- 本版本的容器镜像地址按仓库 owner 变化；部署时请使用对应仓库命名空间下的 GHCR 镜像。
- Docker Hub 仍使用既有 `seakee/cpa-manager-plus` 目标，并在未配置 Docker Hub 凭据时自动跳过。
