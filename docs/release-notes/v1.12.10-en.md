## Overview

v1.12.10 fixes the container publishing path for public repositories: GHCR images are now published under the current repository owner namespace, avoiding permission mismatches when Actions tries to access a package owned by another organization.

## Highlights

### Fixes

- The Release workflow derives the GHCR image address from the current repository owner, allowing a public repository to publish with its own Actions `packages: write` permission.
- Native packages, GitHub Releases, and Telegram notifications continue to use the existing release flow.

## Upgrade Notes

- The container image address follows the repository owner; deployments should use the GHCR image in that owner namespace.
- Docker Hub continues to use the existing `seakee/cpa-manager-plus` target and is skipped automatically when Docker Hub credentials are not configured.
